# Grammar data tables

All files are UTF-8 TSV, `#` lines are comments.  Spoken forms are Turkish
lower-case (`İ → i`, `I → ı`).

| file | content | source / licence |
|---|---|---|
| `currency.tsv` | spoken currency → symbol (+ minor unit) | hand-written (Apache-2.0) |
| `units.tsv` | spoken unit → abbreviation | hand-written |
| `lexicon_entries.tsv` | spelled acronyms → written (`ka de ve` → KDV) | hand-written |
| `brands.tsv` | brands/products incl. Turkish mis-hearings (`vatsap` → WhatsApp) | hand-written |
| `brands_extra.tsv` | ~700 well-known businesses, brands and Turkish institutions | curated list (Apache-2.0); single Turkish common words are filtered out by hand |
| `domains.tsv` | mis-heard e-mail domains → canonical label (`cimil` → gmail) | hand-written |
| `email_providers.tsv` | second-level labels of free e-mail providers | generated from [Kikobeats/free-email-domains](https://github.com/Kikobeats/free-email-domains) (MIT, © 2017 Kiko Beats) |

Hand-written entries always take precedence over generated ones.  To add a
brand: one line in `brands.tsv`; to add a mis-heard domain: one line in
`domains.tsv`.  `brands_extra.tsv` is a curated list, not generated by the
build; edit the TSV directly.
